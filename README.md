
# GST Rate Finder Application

## Project
BBA FinTech Practical Project

## Technologies
- Python
- Pandas
- Streamlit

## Features
- Product Name Search
- HSN Code Search
- GST Rate Information
- Tax Classification
- Category Browsing
- GST Calculator
- CSV Download
- Official Source References

## Run Locally

Install libraries:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Database
The gst_data.csv file stores product information.

Only officially verified product records should be
marked as Verified.
